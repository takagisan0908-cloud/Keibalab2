# 競馬AIラボ（UMAI-LAB）🐎

ブラウザだけで動く競馬予想Webアプリです。
**ファイルは `index.html` の1つだけ**。サーバーもアカウントも不要で、インターネット上のどこか（無料ホスティング等）に置けば **URLを開くだけで毎週使えます**。

> 出馬表の文字読み取り(OCR)に使う学習データを最初の1回だけCDNから取得します。
> また「netkeiba URLから直接取込」を使うと、netkeibaのページ/オッズAPIへ接続します。
> それ以外の 入力・予想計算・レースシミュレーションは **すべてあなたのブラウザ内だけで動作** し、レース予想データが外部に送信されることはありません。

## 使い方（毎週の流れ）

1. ブラウザで `index.html` を開く（または公開URLへ）。
2. 「① データ入力」で レース名・距離・馬場・クラスを入力。
3. **入力は次のどちらでも**：
   - **(おすすめ) URL取込**：netkeibaのレースURLを「🔗 URLから直接取込」に貼り、①出馬表 ②単勝オッズ の順に取込（出馬表は中継設定が必要。上の表参照。オッズは設定不要）。
   - **スクショOCR**：netkeiba の対象レースでスクリーンショットを撮る。
     - 📋 出馬表 → 馬リスト作成
     - 💹 単勝オッズ → オッズ反映（1頭分のスクショでも可）
     - 🏇 調教タイム / ⏱ 持ちタイム → 馬名の割当確認ダイアログが出るので「取り込む」
5. 表の中で 読み間違い・脚質(逃げ/先行/差し/追込)・印 を手直し（任意）。
6. 「② 展開予想・AI印」で ペース診断・AI印・買い目・妙味を確認。
7. 「③ レースシミュレーター」で **▶ 出走させる** → 走りを観戦。**⏩ 100回モンテカルロ集計** で確率を確認。
8. 同じレースの歴史が知りたい時は「⑥ 重賞データ分析」タブの **「🏛 このレースの過去データ」** で過去10年を取得・表示。過去の馬券内(3着以内)に入った馬の脚質割合や各年の1〜3着が確認できます（netkeiba中継設定が必要です。①②と同じ経路。旧「過去データ」タブは⑥内に統合しました）。
9. 入力内容は自動保存。翌週も同じURLで新規レースを作ってOK。

## URL取込のしくみ（スクショが苦手な方へ）

①タブ上部の「🔗 netkeiba URLから直接取込」に、**netkeibaのレースURL**（例 `https://race.netkeiba.com/race/shutuba.html?race_id=202609040211`）を貼り付けます。

- **「② 単勝オッズを取込」は追加設定なしで動きます**。netkeibaのオッズAPIへJSONP方式で問い合わせ、馬番ごとの単勝・人気を入力します。
- **「① 出馬表＋レース情報を取込」は、小さい中継(リレー)が1つだけ必要**です。理由: ブラウザは別サイトのHTMLを直接読むことを(CORSで)制限しており、netkeibaは許可していません。中継を1つ作れば、以降は毎週URLを貼るだけで全自動になります。

中継の作り方は「URL取込の通信設定」を開くとアプリ内にも表示されます。

| 公開先 | 中継の用意 | 手順 |
|---|---|---|
| **Vercel（推奨）** | 同梱ファイル使用 | `keiba-lab-vercel.zip` の中身（index.html ＋ `api/race.js` ＋ アイコン類）をそのままデプロイ → `/api/race` が有効。公開後はアプリの「🔧 中継を診断」で確認 |
| Cloudflare Pages | 同梱ファイル使用 | `keiba-lab-cloudflare-pages.zip` の中身（`functions/api/race.js` 同梱）を `npx wrangler pages deploy .` → `/api/race` が自動認識 |
| GitHub Pages 等(静的のみ) | Cloudflare Worker | 同梱 `worker-relay.js` を Cloudflare Workers に貼り付け「Deploy」→ 出たURL(例 `https://xxxx.workers.dev`)をアプリの「カスタム中継URL」に保存 → 接続テスト |

※ 中継は「渡されたURLのHTMLを返すだけ」の汎用リレーです。netkeibaの利用規約をご確認のうえ、ご自身の予想用途でお使いください。

## トラックバイアス（当日の馬場傾向）の使い方

同じ開催で走り終えた前レースの結果を読み込むと、**今日のこの馬場のクセ**を判定し、AI印の「展開適性」に自動反映します（逃げ・先行と差し・追込の評価が補正される）。反映時はAI印の上部に「トラックバイアス『先行・前残り有利』を反映」と表示されます。

- **自動取込**: 対象レースのURLを「🔗 URLから直接取込」に入れておき、②タブのトラックバイアス欄で「🔍 前レース結果を自動取込」を押すと、同日の1R〜直近レースの結果を取得。馬券内の3頭（馬番・人気・単勝・上がり・勝ち時計・枠）を記録します（※出馬表URL取込と同じ中継設定が必要）。
- **4角位置の入力**: 自動取込では4角通過位置は未設定です。競馬場サイト/映像などで見た各馬の位置を「前(1-3) / 中(4-6) / 後(7-)」ボタンで設定してください（ボタンは行内の各馬にあります）。3頭分以上入ると判定が出ます。
- **手入力**: 中継未設定でも、下の詳細欄に `阪神1R 芝1400 良 | 1着:3(2) 2着:7(5) 3着:1(9) | 1:21.3` の形式で1レースずつ貼り付け可能（括弧=4角位置）。
- 表示される指標: 馬券内の4角位置構成（前/中/後の割合バー）・判定（先行有利/フラット/差し有利）・当日の時計水準（概算基準比）・決着傾向（堅い/波乱含み）・枠位置（内外）。「持ちタイム」観点は、この時計水準＋各馬の持ちタイム比較の両方で確認できます。
- 判定はあくまで過去数レースの統計による**参考情報**です。直近レースに偏る・サンプルが少ない場合は参考度が下がる点にご注意ください。

## 入力のヒント

- スクショは **文字が大きめ・まっすぐ・鮮明** に（縦長ページは上下2枚に分けても良い）。
- OCRは100%ではありません。**必ず下の出馬表で確認・修正** してください。
- URL取込を使うとOCRより正確です（出馬表の構造を解析して取込）。
- 表のセルは全部クリックして直接編集できます（ⓧ で行削除、「馬番順に並べ替え」ボタンあり）。
- テキストが手に入る場合は「テキスト貼り付けで取込」も使えます。
- レース距離を入力すると「持ちタイム比較」が有効になります。

## 数字の計算ロジック（ざっくり）

- **ペース診断**: 逃げ+先行の頭数とその実力、距離・馬場から スロー⇔ハイ を0〜1で採点。
- **AI印**: 5つの評価列を馬ごとに0〜1へ正規化し、重み付きで合算 → ソフトマックスで各馬の勝率に変換。※ 入力が無い列は他馬より低めの標準値で扱います。
- **妙味**: `AI勝率 × 単勝オッズ`。1.0超なら市場がAIより軽視＝妙味あり。
- **シミュレーション**: 1回の走りは AI勝率を強さに変換した乱数試行。単発は運が大きいので、判断は**100回集計**で。

- 原因: 起動処理 `boot()` は `initXxx()` を順番に呼びますが、その中の1つ（開催日カレンダー `initKaisai`）が、**現在のHTMLに存在しないボタンID（旧ピッカー `kaiFetch` 等）** に `on('kaiFetch', ...)` で配線しようとして例外を投げ、**それ以降の初期化（①の日付ピッカー・全馬プロフィール・⑥のカレンダーと分析ボタン・賭け金計算・ライブ等）がすべて実行されない**状態でした。JavaScriptのエラーは画面に出ないため「ボタンを押しても無反応」「年度の選択肢が空」に見えていました。
- 対策1: `on()` を**要素が無ければ何もしない**安全な実装に変更し、HTMLに無いUIは `bindIf()`（あれば配線する版）に切り替えました。
- 対策2: `boot()` の各初期化を `safeInit()` で包み、**1つ失敗しても残りは必ず実行**されるようにしました。失敗した初期化はコンソールに警告としてまとめて出し、トップの状態表示にも「⚠ 一部の初期化で警告」と出ます（今後この種の不具合を隠さないため）。
